## Contents

The notes folder holds these items.

- **`.plans-vault`:** An empty marker file.
  It lets a script walk up from a path inside the notes folder.
- **`index.md`:** A short landing note.
  `plans-resolve` creates it if it is missing and never overwrites it.
- **`inbox/`:** The inbox items.
- **`plans/`:** The plans.

## Index note

- The index note has a heading with the repository path.
- The index note has two short sentences that say where inbox items and plans live.
